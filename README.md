# 嵌入式硬件工程师知识题库 — 站点产物

本仓库只存放**构建后的静态文件**，通过 GitHub Pages 发布。

- 站点地址：https://hovy79.github.io/
- 源码、数据维护工具与文档在私有仓库 `embedded-hw-quiz`
- 本目录由 `npm run deploy` 生成，请勿手工修改

## 内容已加密

`data/content.enc.json` 是 AES-GCM 加密的内容包，需要访问口令才能解密。
仓库中不含任何明文题库数据。

## 内容量

- 知识库：59 个知识点（硬件 32 / 嵌入式 27）
- 面试题库：168 道（硬件 89 / 嵌入式 79）
- 目标公司档案：16 家桂林企业，含推荐项目与面试问答
